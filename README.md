# 📊 Agregador de Dados para Declaração de Imposto de Renda

Ferramenta desenvolvida em Microsoft Excel projetada para consolidar, validar e organizar informações fiscais essenciais, otimizando o preenchimento da declaração anual de Imposto de Renda de Pessoa Física.

Projeto prático desenvolvido como parte da formação na **DIO (Digital Innovation One)**.

---

## 🎯 Objetivo do Projeto

Centralizar dados dispersos (rendimentos tributáveis, despesas dedutíveis e evolução patrimonial) num único ambiente estruturado, eliminando inconsistências através de validações automáticas e simplificando a prestação de contas com o fisco.

## ⚙️ Funcionalidades Implementadas

* **Menu de Navegação Rápida:** botões interativos com hiperligações para trânsito direto entre folhas e links para serviços essenciais da Receita Federal.
* **Validação de Dados:** restrições configuradas para garantir formatação adequada de valores monetários, categorias predefinidas por listas suspensas e controlo de preenchimento.
* **Separação por Módulos:**
  * Rendimentos Tributáveis e Isentos.
  * Despesas Dedutíveis (Saúde, Educação, Dependentes).
  * Evolução de Bens e Direitos.
* **Quadro de Apuração:** fórmulas dinâmicas (`SOMA`, `SOMASE`, `SE`) para apuração instantânea dos totais por categoria.
